# 점심, 뭐 먹지? — 함께 정하기 버전

## 정산하기

참여자를 먼저 등록하고 점심, 카페 같은 정산 묶음을 추가합니다. 묶음마다 결제자와 식당 이름을 정하고 개인 메뉴 및 공용 메뉴를 입력할 수 있습니다. 공용 메뉴의 원 단위 나머지는 등록된 참여자 순서대로 1원씩 배분하므로 합계가 정확히 맞습니다. 여러 묶음의 결제액과 본인 부담액을 상계해 송금 목록을 표시합니다.

정산 초안은 브라우저의 `localStorage`에 자동 저장됩니다. 새로고침 후에도 같은 브라우저에서 이어서 편집할 수 있습니다. 다른 기기와 동시 편집하는 기능은 제공하지 않습니다. 이 방식은 기존 D1 테이블과 충돌하지 않으며 데이터베이스 마이그레이션이 필요하지 않습니다. `npm test`로 정산 계산을 확인할 수 있습니다.

기존 ZIP의 식당 찾기와 포인트 정산을 유지하고, 공유 모임 기능을 추가한 버전입니다.

## 새 기능

- 2~30명 식당 모임 만들기 → 링크 공유 → 이름별 참여
- 식당별 가고 싶어요(♡) / 오늘은 별로(×) 선택 및 집계, 제외 식당 표시
- 만날 장소 4개 중 선택, 11시 또는 12시의 분 단위 시간, 당직이면 12:00 이후로 자동 설정
- 추천 장소(최다 선택) 및 시간(참여자의 가장 늦은 출발 가능 시간) 표시, 최종 식당·장소·시간 저장
- 점약 날짜 모임 만들기 → 달력에서 가능한 날 선택 → 날짜별 가능 인원 집계 및 최종 날짜 저장
- 기존 정산 카드와 네이버 지도 링크 유지

## 배포: Cloudflare Workers + D1

정적 화면과 공유용 데이터베이스를 한 주소에서 운영합니다. Cloudflare 계정이 필요합니다.

1. 이 폴더에서 `npm install`을 실행합니다.
2. `npx wrangler login`으로 본인 계정에 로그인합니다.
3. `npx wrangler d1 create lunch-together`를 실행합니다.
4. 출력된 `database_id`를 `wrangler.jsonc`의 `00000000-0000-0000-0000-000000000000` 대신 넣습니다. `binding` 값 `DB`는 유지합니다.
5. `npm run db:remote`로 데이터베이스 테이블을 만듭니다.
6. `npm run deploy`를 실행합니다. 출력되는 `https://lunch-together.<계정>.workers.dev` 주소를 동료와 공유합니다.

로컬 테스트는 4번 뒤 `npm run db:local`을 실행하고 `npm run dev`로 시작할 수 있습니다. 업데이트할 때는 이 폴더에서 다시 `npm run deploy`를 실행하면 됩니다. 같은 D1 데이터베이스 ID를 유지하면 이전 모임 데이터도 이어집니다.

이 ZIP의 `index.html`을 파일로 직접 열거나 정적 호스팅에만 올리면 공유 모임 기능은 동작하지 않습니다. 공용 저장소와 API가 함께 배포되어야 합니다.

## 사진

원본 ZIP의 사진은 전부 480×480 WebP입니다. 현재 파일만 확대해서 저장해도 실제 화질은 올라가지 않습니다. 교체할 원본 사진을 확보하면 `dist/assets`에 넣고 `dist/index.html`의 `restaurants` 배열에서 해당 식당의 파일명을 새 파일명으로 바꾸면 됩니다. 식당과 무관한 일반 음식 사진으로 임의 교체하면 오해를 줄 수 있어 기존 사진을 유지했습니다.

## 이용 시 참고

모임 링크를 아는 사람은 결과를 볼 수 있습니다. 각 참여자의 수정 정보는 참여한 브라우저에 저장되므로, 같은 브라우저에서 다시 접속하면 자기 응답을 수정할 수 있습니다. 다른 브라우저에서는 같은 이름으로 다시 참여할 수 없습니다. 최종 결정은 참여자라면 저장할 수 있습니다.
